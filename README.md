## 🧰 完整的 5 大工具矩阵

本套件采用现代化桌面架构，包含以下 5 个独立组件：

### 1. 🎯 主程序 (`ai_答题工具主程序.exe`)
- 支持专项练习（指定题型与数量）与模拟考试（按比例随机抽题）。
- 内置插件工具箱，自动集成其他所有扩展工具。
- 答错自动记录，配合错题本实现闭环复习。

### 2. 📂 题库格式转换器 (`题库文件格式转换器.exe`)
- 兼容 Excel (`.xlsx`)、CSV、TXT。
- 智能表头猜测与字段映射。
- 自动推断题型（根据答案智能判定单选、多选、判断），自动清洗判断题答案（T/F/√/× 统一转换）。

### 3. 🔄 题库整合器 (`题库文件整合器.exe`)
- 支持多文件一键批量合并。
- 核心查重算法极度宽容（忽略所有空格、标点符号、大小写、全角半角），精准剔除重复题。

### 4. 🔍 题库智能搜索器 (`题库智能搜索器.exe`)
- 边打字边过滤的实时搜索体验。
- 支持题目、选项、答案全字段模糊匹配。

### 5. 📕 错题本管理工具 (`错题本管理工具.exe`)
- 自动读取主程序生成的 `错题本.csv`。
- 可勾选已掌握的题目一键删除。
- 支持将错题一键导出为新的题库，方便进行“错题重考”。

## 🚀 快速开始

1. 前往 [Releases](这里换成你的Release链接) 页面，下载最新的 `.zip` 压缩包。
2. 将压缩包解压到一个**纯英文或无特殊字符的文件夹**中（确保所有 `.exe` 都在同一个文件夹内）。
3. 双击 **`ai_答题工具主程序.exe`** 即可启动。
4. 初始无题库时，可使用转换器生成标准的 `ict_questions.csv`，或直接通过主程序手动导入题库。

## 💻 开发者的话 (For Developers)

- **技术栈**：`Python 3.11` + `Tkinter` (GUI) + `Pandas` (数据处理) + `PyInstaller` (打包)
- **架构设计**：严格遵循 DRY（Don't Repeat Yourself）原则。抽离了 `common_utils.py` 作为底层通用库（包含路径兼容、万能防乱码读取、超级数据清洗、统一 UI 组件），极大降低了代码耦合度。
